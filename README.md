# Panduan Keamanan Android dan Browser (Bahasa Indonesia)

Repositori edukasi terbuka tentang keamanan perangkat Android, perlindungan akun, dan cara menilai keamanan situs web. Materi ini bukan layanan transaksi game atau aplikasi unduhan.

## Daftar panduan
- [Memeriksa keamanan situs di Android](panduan/keamanan-situs-android.md)

## Prinsip editorial
- Utamakan langkah yang dapat diuji, bukan janji bahwa sebuah situs pasti aman.
- HTTPS melindungi koneksi, tetapi tidak membuktikan reputasi pengelola situs.
- Jangan memasang APK dari sumber tidak tepercaya atau membagikan OTP.
- Tautan eksternal hanya ditambahkan bila benar-benar mendukung topik dan kebijakan platform mengizinkan.
